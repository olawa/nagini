# nagini

En Hydra-Genetics/Snakemake-pipeline för Nanoporedata. Pipelinekörningen kan
starta från FASTQ, oalignerad BAM eller redan alignad BAM och producerar
alignments, coverage-QC, filtrerade och normaliserade småvarianter,
strukturella varianter, sammanfattade translokationer och en Excelrapport.
Småvarianter kan annoteras offline med VEP.

Se [README](../README.md) för inputformat, offline-förberedelse och körning.
